# Code of Conduct

## The short version

Be decent. Assume good faith. Argue about the code, not the person.

## Standards

Expected: respectful and constructive communication, accepting that a maintainer may decline a
contribution, focusing on what is best for the project, showing patience with people who are
learning.

Not accepted: personal attacks, harassment of any kind, demeaning or discriminatory comments,
publishing others' private information, or sustained disruption of discussion.

Note that some pull requests will be declined on principle rather than on quality — see the scope
section in [CONTRIBUTING.md](CONTRIBUTING.md). Disagreeing with that is fine; pressuring
maintainers over it is not.

## Scope

Applies in all project spaces — repository, issues, pull requests, discussions — and when
representing the project publicly.

## Enforcement

Report concerns to the maintainer via a private GitHub message or a security advisory if the
matter is sensitive. Reports are handled confidentially. Responses range from a warning to a
permanent ban, at the maintainer's discretion.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1.
